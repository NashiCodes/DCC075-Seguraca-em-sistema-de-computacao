# Exercícios de Criptografia em Java

## 1. Cifra de César
Programa que criptografa uma mensagem utilizando a Cifra de César, deslocando as letras de acordo com uma chave de 1 a 25.

## 2. Criptoanálise por Frequência
Programa que conta quantas vezes cada letra aparece em um texto e calcula sua porcentagem de ocorrência.

## Requisitos
- Java JDK instalado.
- Terminal ou IDE Java.

## Como executar

### Cifra de César

1. Abra o terminal na pasta onde está o arquivo `CifraCesar.java`.
2. Compile o programa:

   ```bash
   javac CifraCesar.java
   ```

3. Execute:

   ```bash
   java CifraCesar
   ```

4. Digite a mensagem e a chave de deslocamento.

### Criptoanálise

1. Abra o terminal na pasta onde está o arquivo `Criptoanalise.java`.
2. Compile o programa:

   ```bash
   javac Criptoanalise.java
   ```

3. Execute:

   ```bash
   java Criptoanalise
   ```

4. Digite o texto que deseja analisar.
